A single-line joke giving an excuse for a missed deadline, written by a tiny deterministic program. The excuse is a setup-then-confession turn: the narrator lists everything that was ready — alarm, laptop, notes — and then blurts the real reason at the very end, the way a cornered person actually would. No randomness, no network, no dependencies: `main.ts` writes the same fixed line to `$MAKEFUN_OUTPUT_DIR/entry.txt` on every run, validated to be one line of 1–200 characters with no trailing newline.

## Run it

```sh
node main.ts
```
